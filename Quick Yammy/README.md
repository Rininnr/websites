# Quick Yammy: Beispiel-Website, Flyer und Visitenkarten

Inhalt
- index.html: Entwurf der Website fuer Quick Yammy (Wiedner Hauptstrasse 3, 1040 Wien). Doppelklick, dann oeffnet sie im Browser.
- werbung/visitenkarte-flyer.html: Flyer (A4) und Visitenkarten (85 x 55 mm) zum Drucken.

Wichtig
- Nur ein Entwurf. Ohne Erlaubnis des Inhabers nicht veroeffentlichen.
- Angebot: 300 EUR einmalig plus 29 EUR pro Monat (Wartung, Hosting-Hilfe, Aenderungen).
- Platzhalter in eckigen Klammern ersetzen: Name, Telefon, E-Mail, Impressum, Datenschutz, QR-Code.
- Zitate in der Seite sind Auszuege aus oeffentlichen Bewertungen, vorher mit dem Inhaber abstimmen.
- Flyer drucken: im Browser Strg+P, Hintergrundgrafiken einschalten.
- Auf der Seite gibt es keine Fotos. Eigene Fotos vom Essen und Lokal einbauen (nicht die von Rosi's).
- Vor dem Live-Gang pruefen, ob unter quicknyummy.com schon jemand eine Seite baut.
